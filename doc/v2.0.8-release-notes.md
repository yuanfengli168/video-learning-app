# Video Learning App v2.0.8

> **MVP2.0 — Successfully Finished 🎉**
> This is the "v1.0" of the MVP2 track.

---

## Highlights

- **Bulk upload up to 10 GB** — raised from 2 GB. Hardened for batch uploads (3+ files at 1+ GB each).
- **Per-step timing** in the status badge — `ready · T:0:55, G:0:44` shows you how long the transcribe and the LLM materials generation each took, instead of one misleading total.
- **Discuss-tab clickable timestamp citations** — click `[2:35]` in a chat answer to jump the video to that moment and highlight the transcript.
- **Anti-drift language policy** — long multi-window transcribes no longer drift to English on Chinese (or other non-English) videos. Locks the detected language for the whole file.
- **Whisper model picker with 5 options** — `tiny` / `base` / `small` / `medium` (manual) + `local-large-turbo` (smart pick = MLX Whisper Large V3 Turbo on Apple Silicon).
- **Collapsible section-videos panel on the video page** — switch videos in 1 click, no more "back to course" round-trip. Sort by name/date, state persists in localStorage.
- **Logout fix** — anonymous visits to deep links (`/video/`, `/course/`, `/chat-history`) now redirect to login, instead of rendering a phantom page with no data.
- **Single-select tab UI** — clean tab switching on the video page (no more "all 5 tabs visible at once" mess).
- **macOS 12 GB RAM friendly** — works on a stock M1 Mac with 16 GB RAM. MLX backend is optional, falls back to `faster-whisper` if not installed.

## Quick Start

```bash
git clone https://github.com/yuanfengli168/video-learning-app.git
cd video-learning-app
bash scripts/setup.sh                 # Install Homebrew deps + create venv
bash scripts/setup_firebase_key.sh    # After you download the Firebase key
bash scripts/start.sh                 # Start the server (auto-starts Ollama)
```

Open <http://localhost:8000> in your browser. First time? You'll need to:

1. **Install Ollama + pull the model:** `brew install ollama && ollama pull glm-5.2:cloud`
2. **Create a Firebase project** with Google + Email/Password auth enabled. See [`doc/handover.md`](doc/handover.md) for the full walkthrough.
3. **Add `localhost` to Firebase's Authorized Domains** (Authentication → Settings). Otherwise Google sign-in will fail with a "domain not authorized" error.

For the full setup guide, see [`doc/HowToStart.md`](doc/HowToStart.md).

## Known limitations

- **MLX Whisper Large V3 Turbo** is the smart pick on Apple Silicon but requires `pip install mlx-whisper` (not in default `requirements.txt` because it's M-series only). Without it, the app falls back to `faster-whisper` `base` (CPU, slower).
- **`mlx-whisper.transcribe()` is plumbing-only** in this release — it raises `NotImplementedError`. The actual call is a follow-up.
- **Bulk upload is single-process.** 100 videos = serial queue. Worker pool is the next-up feature (tracked in [`doc/MVP2.1-all.md`](doc/MVP2.1-all.md) §3).
- **No scheduled jobs, no mobile app, no cross-device sync.** Single-user, single-device, local-only. Hosted version coming in MVP2.2.

See [`doc/MVP2.0-successfullyFinished.md`](doc/MVP2.0-successfullyFinished.md) §7 for the full list.
