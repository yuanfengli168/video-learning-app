
If Tailscale ever flakes, the iPhone still has the **last cached snapshot on disk** for read-only browsing.

## 1. The blocker we found

The current mkcert cert is generated by `setup.sh`:

```
mkcert -key-file certs/localhost-key.pem -cert-file certs/localhost.pem localhost 127.0.0.1 ::1
```

This produces a cert whose **Subject Alternative Name (SAN)** list is:

```
DNS:localhost, IP Address:127.0.0.1, IP Address:0:0:0:0:0:0:0:1
```

iOS URLSession will reject any connection whose hostname is **not** in the cert's SAN list. So:

| Client | URL it tries | Verifies? |
|---|---|---|
| Mac browser / curl | `https://localhost:8443` | ✅ `localhost` is in SAN |
| iOS Simulator on same Mac | `https://localhost:8443` | ✅ same |
| Real iPhone on same Wi-Fi | `https://192.168.4.26:8443` | ❌ `192.168.4.26` NOT in SAN |
| Real iPhone over Tailscale | `https://<mac-ts>.tailnet.ts.net:8443` | ❌ Tailscale hostname NOT in SAN |

The cert has to be re-issued with the right SAN list. This is a one-liner change.

## 2. Step-by-step plan (the MVP for tonight)

### Step 1 — Reissue the cert with new SANs

The Mac's LAN IP is `192.168.4.26` (as of 2026-07-31). Tailscale hostname will be filled in **after** Tailscale is installed (next step). For now, we reissue with LAN IP only, and add the Tailscale hostname in Step 3.

```bash
# From the project root

# Regenerate cert with new SAN list (localhost + Mac LAN IP)

       -cert-file certs/localhost.pem \
       localhost 127.0.0.1 ::1 192.168.4.26

# Verify
openssl x509 -in certs/localhost.pem -noout -text | grep -A1 "Subject Alternative Name"
# Should now show: localhost, 127.0.0.1, ::1, 192.168.4.26
```

**Why we don't restart the backend yet:** the running `uvicorn` process still has the old cert loaded. We'll restart it after the cert is final (after Tailscale hostname is added in Step 3).

### Step 2 — Install Tailscale on Mac

Tailscale is a free, ~10 MB WireGuard-based mesh VPN. Once installed on both Mac and iPhone with the same account, they can reach each other as if on the same LAN, from anywhere in the world (incl. China — WireGuard is hard for the GFW to detect).

```bash
# Install via Homebrew (already installed per setup.sh)
brew install --cask tailscale

# Launch the menu bar app
open -a Tailscale

# In the menu bar app, click "Log In" → sign in with your Google/Microsoft/GitHub account.
# (User does this manually — Tailscale requires interactive OAuth.)

# After signing in, get your Tailscale hostname and 100.x IP:
tailscale status
# Look for lines like:
#   100.64.x.y   my-mac   my-user@   macOS   -
# The "my-mac" part is the hostname. The full hostname is `my-mac.tailnet-xxxx.ts.net`
# (Tailscale will show this in the menu bar app).
```

### Step 5 — iOS code: editable base URL

**File: `ios/PocketMVP/Config/AppConfig.swift`** — change `baseURL` from a constant to a `@AppStorage`-backed reader.

Before:
```swift
enum AppConfig {
    static let baseURL: URL = URL(string: "https://localhost:8443")!
    // ...
}
```

After:
```swift
enum AppConfig {
    /// Base URL of the Pocket backend. User-editable via Settings screen.
    /// Default is localhost so the iOS Simulator keeps working out of the box.
    /// For real iPhone, user enters their Mac's LAN IP or Tailscale hostname.
    static var baseURL: URL {
        let raw = UserDefaults.standard.string(forKey: "pocket.baseURL")
                   ?? "https://localhost:8443"
        return URL(string: raw) ?? URL(string: "https://localhost:8443")!
    }
    // ...
}
```

**File: `ios/PocketMVP/Views/SettingsView.swift`** — NEW. A simple sheet with:

```swift
import SwiftUI

struct SettingsView: View {
    @Environment(\.dismiss) private var dismiss
    @AppStorage("pocket.baseURL") private var baseURL: String = "https://localhost:8443"
    @State private var testStatus: TestStatus = .idle

    enum TestStatus { case idle, testing, ok, fail(String) }

    var body: some View {
        NavigationStack {
            Form {
                Section("Backend") {
                    TextField("Base URL", text: $baseURL)
                        .textInputAutocapitalization(.never)
                        .autocorrectionDisabled(true)
                        .keyboardType(.URL)
                    Button {
                        Task { await testConnection() }
                    } label: {
                        switch testStatus {
                        case .idle:    Text("Test connection")
                        case .testing: ProgressView()
                        case .ok:      Label("Connected", systemImage: "checkmark.circle.fill")
                        case .fail(let m): Label(m, systemImage: "xmark.octagon.fill").foregroundStyle(.red)
                        }
                    }
                }
                Section("Examples") {
                    Text("• Simulator: `https://localhost:8443`")
                    Text("• Same Wi-Fi: `https://192.168.4.26:8443`")
                    Text("• Tailscale: `https://<mac>.tailnet-xxxx.ts.net:8443`")
                        .font(.caption).foregroundStyle(.secondary)
                }
            }
            .navigationTitle("Settings")
            .toolbar { ToolbarItem(placement: .confirmationAction) { Button("Done") { dismiss() } } }
        }
    }

    private func testConnection() async {
        testStatus = .testing
        guard let url = URL(string: baseURL)?.appendingPathComponent("/api/health") else {
            testStatus = .fail("Bad URL"); return
        }
        do {
            let (data, resp) = try await URLSession.shared.data(from: url)
            if let http = resp as? HTTPURLResponse, http.statusCode == 200 {
                testStatus = .ok
            } else {
                testStatus = .fail("HTTP \((resp as? HTTPURLResponse)?.statusCode ?? 0)")
            }
        } catch {
            testStatus = .fail(error.localizedDescription)
        }
    }
}
```

#### 6a. Enroll in the Apple Developer Program

**User action required.** ~5 min if account is set up, ~24h waiting for
Apple approval, then ~5 min more to get the Team ID.

1. Open https://developer.apple.com/account/enroll
2. Sign in with your Apple ID (or create one)
3. Choose **Individual** entity type (unless you have a company with D-U-N-S)
4. Fill in legal name (must match government ID), address, phone
5. Agree to the Program License Agreement
6. Pay **$99 USD** via credit/debit card
7. Wait for the approval email — usually a few hours, sometimes instant
8. Once approved, **get the Team ID**:
   - Open Xcode → Settings → Accounts (⌘,)
   - Click `+` → Apple ID → sign in with the same Apple ID
   - Your team appears in the list. Click it.
   - The **Team ID** is shown — 10-character alphanumeric like `A1B2C3D4E5`
9. **Paste the Team ID to the assistant** so we can update the project file


## 3. What we deliberately deferred (parked for v0.2)

These are real polish items but **not needed for the trip**. Each is a small follow-up commit when there's time.

### Deferred A — Stale-data banner
When `/m/snapshot` fails because the Mac is unreachable, show a banner:
"Showing cached data from 2h ago. Mac unreachable. [Retry] [Settings]"

Today the iOS app silently shows stale data. The user has to know to manually pull-to-refresh. For 17 days this is a UX risk — if user uploads new videos on Mac via AnyDesk, iPhone won't know.

**Where it goes:** `SnapshotStore.swift` → expose `lastSuccessfulSyncAt: Date?` → `CourseListView` shows banner when sync fails and last success > N hours ago.

### Deferred B — QR-code base URL setter
Mac displays a QR in the terminal that encodes the URL. iPhone scans it → URL pre-fills Settings. Saves typing the long Tailscale hostname.

**Where it goes:** New `scripts/print-connection-qr.sh` (uses `qrencode` or python `qrcode`). New camera-scan button in `SettingsView` (uses `AVCaptureSession`).

### Deferred C — Dynamic LAN IP detection
Today we hard-code `192.168.4.26`. If user moves to a different Wi-Fi, the LAN IP changes and Settings default breaks.

**Where it goes:** Replace constant in `AppConfig.swift` with a `BonjourService` browser or just a smarter Settings default that reads from `en0`.

### Deferred D — Free signing validity
If user has no paid Developer account, Xcode's free Personal Team signing expires every 7 days. Trip is 17 days. We need a paid account, OR re-sign the app every 7 days via Xcode.

**Mitigation:** Sign up for paid Developer account ($99) before leaving. Or accept that the user will need to re-sign from Mac via AnyDesk on day 8.

### Deferred E — Full iPhone offline mode
Today, even after caching the snapshot, opening a chat / refreshing / new uploads requires Mac. True offline mode would mean:
- Local Ollama on iPhone (impossible — iOS can't run Ollama)
- Or: chat is read-only offline (browse cached answers, no new questions)

Not pursuing this trip. Just docs it as out of scope.

### Deferred F — mDNS auto-discovery
Discover Mac on LAN without typing the IP. Apple's Bonjour.

**Where it goes:** `_http._tcp` service in Mac's uvicorn, browse in iOS via `NetServiceBrowser`. Replaces the need to know the LAN IP at all.

### Deferred G — Real iPhone voice I/O
Already documented in `pocket-v0.1-plan.md` §10 as v0.2. No change here.

## 10. Why this design

- **Why Tailscale over a public domain:** Tailscale gives you a stable hostname, end-to-end encryption, no DNS/router/firewall juggling, no public exposure, and works from China. A public domain requires DNS, port-forwarding, cert renewal, and is at the mercy of the GFW. Tailscale is one install + one sign-in.
- **Why editable base URL instead of mDNS:** mDNS only works on the same LAN. Tailscale is cross-network, so we need an explicit URL anyway. The editable TextField is simpler than mDNS + works for both LAN and Tailscale.
- **Why we don't try to auto-detect the Mac:** Because the iPhone needs to know *some* identifier before it can connect. Either a hostname, an IP, or a service-browse result. Hard-coding a default + letting the user edit is simpler than running a network service browser that may or may not work depending on the network.
- **Why keep `localhost:8443` as the default:** Because the iOS Simulator on the same Mac keeps working out of the box. The user only has to change the URL when they use a real device on a different network.
- **Why we don't store anything in iCloud:** Because the user might use the app on multiple devices. Per-device `@AppStorage` keeps it simple. KVS would be a future enhancement.

## 12. Glossary

- **SAN (Subject Alternative Name):** A field in an X.509 certificate that lists all hostnames/IPs the cert is valid for. TLS clients check this against the URL they connected to. Mismatch = cert rejected.
- **mkcert:** A zero-config tool that creates locally-trusted HTTPS certs. Free, open source, single binary. <https://github.com/FiloSottile/mkcert>
- **CAROOT:** The directory where mkcert stores its root CA (`$(mkcert -CAROOT)` on Mac).
- **Tailscale:** A WireGuard-based mesh VPN. Free for personal use. Creates a private network across devices anywhere in the world.
- **WireGuard:** The actual VPN protocol Tailscale uses. State-of-the-art cryptography, very fast, very small. Hard to fingerprint/block because packets look like UDP noise.
- **DERP (Designated Encrypted Relay for Packets):** Tailscale's relay servers for when direct peer-to-peer isn't possible (e.g. symmetric NAT). Falls back automatically.
- **GFW (Great Firewall):** China's internet censorship system. Blocks VPN protocols by deep-packet-inspection sometimes. WireGuard generally slips through; OpenVPN usually doesn't.
- **Apple Developer account (paid):** $99/year. Required for App Store distribution + for indefinite device signing.
- **Personal Team (free signing):** Xcode's free signing tier. Apps expire every 7 days and must be re-signed.
- **UDID:** A 40-character unique device identifier for an iOS device. Used to target builds to a specific device.
