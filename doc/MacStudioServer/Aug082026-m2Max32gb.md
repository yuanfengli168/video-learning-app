### OS decision: Install Sequoia 15.7.9

**Why Sequoia 15.7.9 (not Sonoma 14.8.9, not Tahoe 26.6.1)**:

| Option | Verdict | Reason |
|---|---|---|
| Stay Sonoma 14.2 | ❌ No | Missing ~1 year security patches, unsafe for production |

| Tahoe 26.6.1 | ❌ No | 1 year newer than MBP = untested, breaks dev↔prod parity |

Key insight: `softwareupdate --list` only shows updates for *current* macOS. To see all available installers (including Sequoia on Sonoma), use `softwareupdate --list-full-installers`. This is how we discovered Sequoia IS available on Mac Studio despite `--list` only showing Sonoma + Tahoe.

### MBP vs Mac Studio: KEEP THEM ON DIFFERENT PATCH LEVELS

- **MBP**: stay on Sequoia **15.6.1** (working perfectly, 623/623 tests pass)
- **Mac Studio**: install Sequoia **15.7.9** (latest stable, gets security patches)
- Same major version (both 15.x) → same APIs, same packages, no breakage
- Different patch level → enables A/B testing if any macOS regression appears on Mac Studio
- **Do NOT upgrade MBP** to match Mac Studio — fixes nothing, risks breaking dev env

### Why not "Tahoe for longer support" (rejected)

Gained 1 year of support we'll never use (Mac Studio replaced before 2029). Lost certainty that the app works (no MBP to test against). Bad trade.

### SSH: `--list-full-installers` vs `--list` (the discovery)

The Mac Studio originally *appeared* to be locked to Sonoma only. This was wrong — `softwareupdate --list` filters to current-OS updates only. The right check is `--list-full-installers`, which lists all full installers Apple provides for this Mac's hardware/firmware. Always use this when checking upgrade options:

```bash
softwareupdate --list-full-installers    # all macOS installers available
softwareupdate --list                    # only updates for current macOS
```

### Remote management reality: AnyDesk is primary (no Tailscale)

MBP at office ≠ Mac Studio at home = different networks. SSH via `.local` / LAN IP / public IP **does not work** cross-network without VPN.

**Working remote access stack** (no Tailscale needed):

| Tool | Cross-network? | Use case |
|---|---|---|
| **AnyDesk** | ✅ Yes (relay servers) | Primary remote GUI + open Terminal inside |
| **Chrome Remote Desktop** | ✅ Yes | Backup GUI access |
| SSH (same network only) | ❌ No | Fast CLI when both machines on home Wi-Fi |
| Wake-on-LAN | ❌ Same-network only | Backup wake, not from office |

**Do NOT add Tailscale** unless SSH-from-office becomes a real recurring need. AnyDesk covers daily management. 




## Check and install the macOS installer:
### checks
✅ Pre-flight checklist (BEFORE running the install command)
1. Verify the installer (sanity check)
```
# On Mac Studio:
ls -lh "/Applications/Install macOS Sequoia.app/Contents/SharedSupport/"
# Should show:15G SharedSupport.dmg

df -h /
# Should show: ≥25GB free (15GB installer + working space)
```

2. Save your current settings (in case you need to restore)
```
# On Mac Studio:
mkdir -p ~/macos-upgrade-notes# Save current pmset settings:
sudo pmset -g > ~/macos-upgrade-notes/pmset-before.txt

# Save current SSH setting:
sudo systemsetup -getremotelogin > ~/macos-upgrade-notes/ssh-before.txt

# Save your user info:
whoami > ~/macos-upgrade-notes/user.txt
sw_vers > ~/macos-upgrade-notes/macos-before.txt
```

4. Note what's installed (for re-install after upgrade)
```
# On Mac Studio:
# List installed apps:
ls /Applications/ > ~/macos-upgrade-notes/apps-before.txt

# List Homebrew packages (if installed):
brew list > ~/macos-upgrade-notes/brew-before.txt 2>/dev/null

# List Ollama models (if installed):
ollama list > ~/macos-upgrade-notes/ollama-before.txt 2>/dev/null

# List Python packages (if installed):
pip3 list > ~/macos-upgrade-notes/pip-before.txt 2>/dev/null
```

4. Close all open apps
```
# On Mac Studio:
# Close everything: browser, VS Code, Terminal windows, etc.
# Make sure no important work is open
```

1. Plug in power (CRITICAL)
Make sure Mac Studio is plugged into power. If it loses power during the upgrade, you'll have a brick.

1. Verify AnyDesk is running
Make sure AnyDesk is set to start automatically with the system. This way, after reboots, AnyDesk reconnects.
```
# On Mac Studio:
# System Settings → Users & Groups → yuanfengli → Login Items
# Verify AnyDesk is listed

```

7. Mental preparation
⏳ Expect 30-60 minutes of downtime
🚫 Don't interrupt the install
🔌 Mac will reboot multiple times
✅ AnyDesk will reconnect automatically (if configured)


### install
🚀 Run the upgrade
`sudo "/Applications/Install macOS Sequoia.app/Contents/Resources/startosinstall" --agreetolicense --forcequitapps --rebootdelay 5 --passprompt`
Enter your password. Mac reboots. Wait ~1 hour. Reconnect AnyDesk.

🗑️ After successful upgrade: cleanup the installer
The installer takes 15GB of disk space. After upgrade, you should delete it.

Step 1: Verify upgrade succeeded
```
# On Mac Studio (after Mac comes back):
sw_vers
# Should show: ProductVersion: 15.7.9, BuildVersion: 24G830
```

Step 2: Delete the installer
```
# On Mac Studio:

# 1. Verify the installer is still there (sanity check)
ls -lh "/Applications/Install macOS Sequoia.app/Contents/SharedSupport/"

# 2. Delete the installer (sends to Trash)
sudo rm -rf "/Applications/Install macOS Sequoia.app"

# 3. Empty Trash to actually free space
rm -rf ~/.Trash/*

# 4. Verify space freed
df -h /
# Should show: ~15GB more free space

```

Step 3: Verify cleanup```bash
Confirm installer is gone:
ls "/Applications/Install macOS Sequoia.app" 2>&1

Should show: "No such file or directory"
```

## ⚠️ If the upgrade fails mid-install

You'll see:
- Black screen with frozen progress bar for >1 hour
- Mac rebooting in a loop
- Error message saying installation failed

**Don't panic.** Here's what to do:

1. **Hold power button for 10 seconds** (force shutdown)
2. **Press power button once** to turn it back on
3. **Hold power button** again when you see the Apple logo → "Loading startup options"
4. **Choose "Options"** → opens **Recovery Mode**
5. **Utilities → Reinstall macOS**
6. This re-installs Sequoia without erasing your data

If that doesn't work:

7. **Utilities → Disk Utility → Erase Mac** (factory reset)
8. **Utilities → Reinstall macOS**

Either way, your Mac Studio will work again.
