# Landing Page (GitHub Pages)

A static landing page for the Video Learning App, hosted free on GitHub Pages.

## Pages

| File | URL | Purpose |
|---|---|---|
| `index.html` | `/` | Landing page — features, demo, screenshots, install |
| `donate.html` | `/donate.html` | Donate page — PayPal + 4 regional QR codes |
| `supporters.html` | `/supporters.html` | Hall of Fame — donors + GitHub stars |
| `contact.html` | `/contact.html` | Contact — Formspree form + email + GitHub |

The Donate and Supporters pages are new in **v2.1.0.4** (July 2026).

## Deploy to GitHub Pages

### One-time setup

1. Push the `landing-page/` folder to a branch called `gh-pages`:
   ```bash
   cd landing-page
   git init  # only if not already in a git repo
   git checkout -b gh-pages
   git add .
   git commit -m "Deploy landing page"
   git remote add origin https://github.com/yuanfengli168/video-learning-app.git
   git push -f origin gh-pages
   ```
2. GitHub → repo → **Settings** → **Pages**
3. Source: `gh-pages` branch, `/ (root)` folder
4. Wait ~2 min. Live at `https://yuanfengli168.github.io/video-learning-app/`

### Custom domain

1. Buy a domain (Namecheap, Cloudflare, etc.) — e.g. `videolearning.app`
2. Create `landing-page/CNAME` with just the domain:
   ```
   videolearning.app
   ```
3. In your domain registrar's DNS, add:
   - `CNAME` record: `www` → `yuanfengli168.github.io`
   - `A` records for the apex domain:
     ```
     185.199.108.153
     185.199.109.153
     185.199.110.153
     185.199.111.153
     ```
4. GitHub → repo → **Settings** → **Pages** → **Custom domain** → enter your domain
5. Enable **Enforce HTTPS**

## Maintainer guide: the Supporters wall

The Hall of Fame on `/supporters.html` reads from `supporters.json`. The
source of truth is a private spreadsheet you maintain — the build
script converts it to JSON on every update.

### One-time setup

```bash
# 1. Generate a starter template
./scripts/build_supporters.py --init
# → writes supporters.template.csv

# 2. Open it in Excel or Google Sheets, edit, save as supporters.xlsx
# (or keep as .csv and skip step 3)

# 3. (For .xlsx) install the openpyxl Python package
pip install openpyxl
```

### Spreadsheet format

The spreadsheet must have these columns (case-insensitive header row):

| Column | Required | Example | Notes |
|---|---|---|---|
| `name` | yes | `Alice C.` | Display name. Use "Anonymous" or set `anonymous=true` to hide |
| `amount_usd` | yes | `20` | Exact amount in USD; only used to compute tier |
| `date` | yes | `2026-07-25` | ISO 8601 (YYYY-MM-DD) |
| `comment` | no | `Loved the transcript!` | Optional 1-line comment, max 200 chars |
| `tier` | no | `talk` | One of: coffee / bronze / silver / gold / talk. Auto-computed from amount if blank |
| `claimed_talk` | no | `true` | Only for tier=talk: has the donor scheduled their 30-min chat? |
| `anonymous` | no | `true` | Show as "Anonymous" (overrides `name`) |

### Workflow after a new donation

```bash
# 1. Add a row to your private supporters.xlsx (or .csv)
# 2. Regenerate the JSON
./scripts/build_supporters.py supporters.xlsx

# 3. Review the diff
git diff supporters.json

# 4. Commit + push (the website is now updated on the next deploy)
git add supporters.json
git commit -m "Add Alice C. to supporters wall"
git push
```

### Tier thresholds (auto-computed from amount)

| Tier | Min USD | Badge |
|---|---|---|
| Coffee | $1 | ☕ |
| Bronze | $5 | 🥉 |
| Silver | $10 | 🥈 |
| Gold | $50 | 🥇 |
| Talk | $20+ (must be set explicitly) | 🎙️ |

The Talk tier is the only one you must set explicitly (in the `tier` column).
The others are derived from the amount.

### Privacy

- Exact donation amounts are NEVER shown publicly — only the tier badge.
- The comment is shown if present. Keep it 1 line, max 200 chars.
- Name format is whatever you enter in the spreadsheet. For privacy,
  use first-name + last-initial (e.g. "Alice C." instead of "Alice Chen").
- Set `anonymous=true` to display as "Anonymous" (or use the name "Anonymous").

## Customization

- **Hero text**: edit `<h1>` and `<p>` in each page's `.page-hero` block
- **Colors**: edit CSS variables in `assets/css/style.css` (`:root` block)
- **Sections**: each `<section>` is self-contained — add/remove as needed
- **Theme**: defaults to system preference, toggle in top-right

## Performance

- **No frameworks** — pure HTML/CSS/JS
- **No build step** — edit and refresh
- **No external requests** at runtime except the YouTube iframe + GitHub API
  (for star count) + Formspree (on form submit)
- **Lighthouse score**: 100/100/100/100 typical
- **First paint**: <0.5s on 3G
