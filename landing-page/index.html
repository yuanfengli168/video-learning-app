What it does

One video in. Six tools out.

Every feature is designed to make you test yourself — not just re-read notes. That's the whole philosophy.

📝

Searchable transcript

Whisper transcribes locally. Click any line to jump the video. Live search with prev/next navigation. Export to MD, JSON, or TXT.

🧠

Clickable mindmap

Every node is a timestamp. Click → video jumps. Even leaf nodes work — the AI walks up the tree to find the nearest parent.

📇

Auto flashcards + quiz

Not just summaries — actual recall tests. Click "Teach me real-world usage" on any flashcard to open a tutor chat.

💬

Discuss the whole video

A ChatGPT-style chat with the full transcript + summary + mindmap as context. Ask "what did the prof mean at 23:15?" — it answers.

⏱️

Topic timestamps

Auto-generated by the LLM. Jump back to the exact 3-minute segment you need to review. No more scrubbing.

🛠️

Plugin Tools

Convert WebM → MP4 in one click. Background worker pool means the transcoder survives tab close. Plugin system designed to grow.

Get started

5 minutes from git clone to ready

macOS, Linux, and Windows. Works on a stock M1 MacBook with 16 GB RAM.

1

Clone & install

git clone https://github.com/yuanfengli168/video-learning-app
cd video-learning-app
bash scripts/setup.sh
2

Pull the LLM

ollama serve &          # auto-started by setup.sh on macOS
ollama pull glm-5.2:cloud # the default LLM (~2 GB)
3

Add your Firebase key

bash scripts/setup_firebase_key.sh
# (paste the JSON you downloaded from Firebase console)
4

Start the app

bash scripts/start.sh
# Open http://localhost:8000

Full guide (troubleshooting, optional MLX backend, Postgres migration): doc/HowToStart.md
